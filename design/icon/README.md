# Icône de l'app

Un ticket de papier avec le J de JentApp et une barre de laiton, sur fond de nuit. Elle reprend la signature du design system : le ticket est la seule surface claire.

| Fichier | Usage |
| --- | --- |
| `icon.svg` | Source. Couleurs : `bg`, `paper`, `on-paper`, `on-paper-muted`, `brand` |
| `icon-512.png`, `icon-192.png` | Manifeste de la PWA, en `any` et en `maskable` : le ticket tient dans la zone sûre |
| `apple-touch-icon.png` | Écran d'accueil iOS (180 px) |
| `favicon-32.png` | Onglet du navigateur |

Le fond est plein, sans coins arrondis : c'est le système qui arrondit. Ne pas ajouter d'ombre ni de dégradé.
